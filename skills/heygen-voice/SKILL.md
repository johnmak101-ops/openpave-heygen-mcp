# HeyGen Voices and Speech

Doctrine status: **[stub — schema-grounded]**. Tool names and descriptions
below come from the live `tools/list` snapshot (2026-11-12). Operational
doctrine is [unverified] unless tagged otherwise — verify with

`../SKILL.md` §4.

## Tools (10)

| Tool | Live description (2026-11-12 snapshot) |
|---|---|
| `list_voices` | List HeyGen Voice voices. type=public lists the instant voices HeyGen provides to every workspace, best first; filter them with language (an ISO 639-1 code; without query or age, voices that speak many languages also match), gender and age, or search them with query. type=private (the default) lists the workspace's own instant and professional clones, newest first, told apart by mode; it takes no filters. Only ACTIVE voices can speak; PENDING voices are still being created. Page with limit and the returned next_token. Pass a returned voice_id to create_speech. |
| `get_voice` | Get one HeyGen Voice voice, the workspace's own or public, and its status: PENDING while being created, ACTIVE when it can speak, or FAILED with a failure_reason. Use it to poll clone_voice, design_voice and create_professional_voice. Honor retry delays or wait 30 seconds between polls. |
| `design_voice` | Design a new HeyGen voice from a description of its age, tone, accent and speaking style, in one language, and save it to the workspace. Returns voice_id; poll get_voice until ACTIVE with a preview_audio_url and let the user listen before using it. An optional speaker image conditions the voice. Design has a daily limit and designed voices count toward the workspace's voice limit. Check list_voices before retrying an unknown outcome; repeating creation can create duplicate work. Media inputs take a HeyGen asset_id or a public https URL, never a local or sandbox path (/mnt/data/..., file://); import or upload the file first and pass its asset_id. |
| `clone_voice` | Create an instant voice clone from one recording of the user's own voice or of a voice they have permission to use. Saves the voice to the workspace and returns voice_id; poll get_voice until ACTIVE, then use it with create_speech. HeyGen applies the workspace's voice limits; if it refuses the request, tell the user why. Check list_voices before retrying an unknown outcome; repeating creation can create duplicate work. Media inputs take a HeyGen asset_id or a public https URL, never a local or sandbox path (/mnt/data/..., file://); import or upload the file first and pass its asset_id. |
| `create_professional_voice` | Create a professional voice clone of the user's own voice or of a voice they have permission to use, by training on at least 20 minutes of recordings of that one voice (up to 10 recordings, 1.5 GB in total). Passing the voice_id of an existing professional voice retrains it instead and replaces its current training. Training takes time: poll get_voice until ACTIVE or FAILED. Honor retry delays or wait 30 seconds between polls. After five minutes, share the status and voice_id so the user can check back later. A new voice needs an available professional-voice slot in the workspace. Professional voices speak only with model heygen-voice-1. Check get_voice before retrying an unknown outcome; repeating creation can create duplicate work. Media inputs take a HeyGen asset_id or a public https URL, never a local or sandbox path (/mnt/data/..., file://); import or upload the file first and pass its asset_id. |
| `delete_voice` | Delete a voice the workspace owns. A professional voice cannot be deleted while PENDING; deleting a pending instant voice cancels it. Confirm the voice with the user first. |
| `create_speech` | Generate speech from text with HeyGen Voice. Use a voice_id from list_voices: type=public for HeyGen's voices, type=private for the workspace's clones. Voice IDs from older HeyGen voice catalogs are refused. Returns an audio URL (WAV by default) and its duration in seconds. Omit model unless the user explicitly asks for one: the server uses heygen-voice-1-turbo-free on a free MCP plan, which speaks instant voices only (every public voice is instant), and heygen-voice-1 otherwise. Set language to the text's ISO 639-1 code or omit it to detect. Set with_timestamps for word and character timings. A 429 for the workspace's daily Turbo Free limit (retryable false) stands until the limit resets: explain it, never retry. A 429 saying free capacity is full (retryable true) is temporary: back off and retry once. After any other generation error or timeout, ask the user before another generation; never retry automatically. Widget-capable chat hosts also display an inline audio player when its bundle is available. Clients without widgets receive the audio URL. Listening, seeking, and downloading do not require another generation call. The player Regenerate button makes one user-requested call that replays the original text, voice, language and speed (the model is chosen for the plan again); do not repeat that call from the conversation. One Create speech selection authorizes one call with the selected voice and one agreed script, not a batch or alternate versions. If the script is ambiguous, ask before generating. After an error or timeout, ask the user before retrying, except one backoff retry of a retryable free-capacity 429. To return only the result without opening the player (for example, several clips generated in parallel), call create_speech_without_player. |
| `create_speech_without_player` | Generate speech from text with HeyGen Voice. Use a voice_id from list_voices: type=public for HeyGen's voices, type=private for the workspace's clones. Voice IDs from older HeyGen voice catalogs are refused. Returns an audio URL (WAV by default) and its duration in seconds. Omit model unless the user explicitly asks for one: the server uses heygen-voice-1-turbo-free on a free MCP plan, which speaks instant voices only (every public voice is instant), and heygen-voice-1 otherwise. Set language to the text's ISO 639-1 code or omit it to detect. Set with_timestamps for word and character timings. A 429 for the workspace's daily Turbo Free limit (retryable false) stands until the limit resets: explain it, never retry. A 429 saying free capacity is full (retryable true) is temporary: back off and retry once. After any other generation error or timeout, ask the user before another generation; never retry automatically. Never opens the audio player on any host: returns the same audio URL JSON as create_speech, so use it when the user does not need to listen inline, such as when a skill or workflow generates several clips in parallel. Use create_speech when the user should listen in the inline player. Each call consumes speech quota; one agreed script authorizes one call. |
| `convert_speech` | Speech to speech: re-voice a recording in an ACTIVE instant voice the workspace owns (from list_voices type=private). Professional clones are not supported. Words and timing stay the same. Returns a WAV URL and duration. Maximum source duration: 300 seconds. OAuth requires a paid plan. Requests use workspace credits. Conversion can take 150 seconds. After an error or timeout, ask the user before another conversion; never retry automatically. Media inputs take a HeyGen asset_id or a public https URL, never a local or sandbox path (/mnt/data/..., file://); import or upload the file first and pass its asset_id. |
| `search_audio_sounds` | Searches the music or sound-effects catalog by natural-language description (`type=music` by default, or `sound_effects`). Returns tracks ranked by similarity, each with a download URL, paginated by cursor. |
